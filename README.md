# 序时 · 作品时间轴

小说、游戏与世界设定的本地桌面时间轴工具。由 **Symplatt** 设计并主导开发，Codex 辅助实现。

**当前版本：1.0.0** · Copyright © 2026 Symplatt. 版权所有。

## 安装与更新

从 [GitHub Release](https://github.com/Symplatt/story-timeline/releases/latest) 下载 `Xushi-Setup-1.0.0.exe`，运行后从桌面或开始菜单打开“序时”。安装包同时交付到本机 `D:\` 根目录。

面向 Windows 10/11 x64，采用当前用户安装，不需要自行安装 Node.js。安装程序写入 Windows“已安装的应用”及卸载注册表项。后续版本使用同一应用标识 `com.symplatt.xushi` 和安装目录覆盖更新。请先关闭旧版再运行新安装程序。

作品数据独立保存在 `%APPDATA%\Xushi\workspace`。覆盖安装及卸载均保留该目录；安装包和公开仓库不包含用户作品。请定期导出完整 JSON 备份。

## 使用

- **时间轴库**：点击左上作品名或“时间轴库”切换、新建、重命名、删除，最多 1000 条时间轴。
- **节点**：每条最多 10000 个。只有事件必填，其余字段均可留空。中央时间轴只能上下滚动，没有任意方向拖动或画布缩放。通过可见区域渲染控制大量节点的 DOM 数量。
- **事件**：卡片保留前 100 个 Unicode 字符，超出显示省略号；点击卡片在右侧看全文。编辑器支持加粗、下划线、斜体、删除线和屏蔽。屏蔽文字显示为黑色矩形，悬停或键盘聚焦揭示。该效果不是加密，JSON 和 Markdown 源文仍包含原文。
- **时间**：由高到低为时代、朝代、历法、日期、时刻，均为文本字段，不限制真实日历范围，允许 `1382.3.5 17:00:73` 等设定。
- **地点和组织**：各有 1—5 级，1 级最高。各层级可独立筛选，多个已选条件同时满足才显示。“显示无地点／组织事件”控制完全未填写该字段的事件是否也纳入结果。
- **国家**：可选单值字段，可筛选。
- **角色**：用空格、换行或 Tab 分隔，没有人为数量上限，自动去重并纳入已有角色清单。拉丁字母使用自然字母顺序；中文采用拼音排序，中文和拉丁文字按中文排序器分组。清单可折叠；删除节点仍保留已有角色以便复用。

## 排序和显示设置

五层时间依次使用数字、字母自然排序，不推断真实历史朝代先后。例如 `纪元2` 在 `纪元10` 之前；时代相同才比较朝代，依次向下。

缺失的层级排在相同上层分组末尾；全空时间排在最后。同一天未填时刻的事件在该天末尾，日期只填 `1234.5` 时排在该月所有具体日期之后，只有 `1234` 时排在该年末尾。相同时间按创建顺序稳定排列。

顶部“显示设置”提供与织灵一致的草木、灰白、烟粉、雾蓝、黑金五套主题。时间层级可分别隐藏，但完整时间仍参与排序。日期可以显示为 `1234.5.6` 或 `1234年5月6日`；两种输入格式排序等价，不符合数字年月日格式的自定义文本保留原样。

主题、日期格式、显示层级、当前时间轴、角色清单折叠、详情面板和每条时间轴的筛选设置自动保存，重新打开不会回到默认值。

## 保存与备份

编辑完成的节点在约 650 毫秒后自动保存，也可以按 Ctrl+S 或点“保存”。新增节点点击“完成”后进入时间轴；未完成的编辑作为草稿持久保存并在重新打开时恢复。切换时间轴前需完成或取消尚未完成的节点。

桌面端每条时间轴独立保存为 JSON，以临时文件、原子替换和上一版 `.bak` 备份保护写入。可解析的备份可用于自动恢复；无法恢复时阻止覆盖损坏原文件并提示错误。导出备份依然必要，备份文件不能替代其他设备上的副本。

## 导入和导出

| 格式 | 范围与用途 |
| --- | --- |
| JSON | 当前时间轴或完整库，包含全部字段、富文本、角色清单和筛选；导入预览后作为新时间轴加入，不覆盖已有作品。单次导入文件最多 512 MB，更大的库应分批备份和导入。 |
| PNG | 当前时间轴的全部节点或当前筛选结果，使用当前主题、日期格式与显示层级；每张最多 14 个节点，自动编号分页。卡片显示前 100 字，屏蔽内容保持黑色。 |
| Markdown | 当前时间轴全部节点或筛选结果，保留完整事件、时间、地点、组织、国家和角色，以及 HTML 形式的文字格式。支持内嵌 CSS 的 Markdown 阅读器可悬停揭示屏蔽内容；其他阅读器的样式支持可能不同。 |

桌面导出使用系统文件对话框，记住最近的导出目录。PNG 分页遇到同名文件时会确认是否覆盖。

## 从源码运行

技术栈：Vue 3、TypeScript、Electron；建议 Node.js 24.x。

```powershell
npm.cmd ci
npm.cmd run dev          # 浏览器开发预览：127.0.0.1:5186
npm.cmd run desktop      # 构建并启动 Electron
npm.cmd test             # 业务与文件存储自动测试
npm.cmd run build        # TypeScript 检查及前端构建
npm.cmd run pack:release # Windows x64 NSIS 安装包
```

浏览器开发模式使用 IndexedDB，和桌面数据分开。批量 PNG 下载推荐使用桌面版，浏览器可能限制连续下载。

桌面交互回归（只使用 `output/desktop-qa` 下的合成数据，按顺序运行）：

```powershell
node tests/desktop-qa.cjs create
node tests/desktop-qa.cjs reopen
node tests/desktop-qa.cjs stress
```

文件存储逻辑在 `electron/store.cjs`；排序、校验和字段结构在 `src/model.ts`；可滚动时间轴、格式编辑器位于 `src/components`；导出逻辑在 `src/export.ts`。
